# 💌 편지를 구글 시트에 모으기 (10분, 무료)

사이트는 서버가 없어서, 그냥 두면 하객이 쓴 편지가 **그 하객의 휴대폰에만** 남아요.
구글 시트 하나를 '편지함 서버'로 쓰면 편지가 시트에 모이고, 모든 하객이 편지함에서 함께 봐요.
신랑신부는 시트를 열어 편지를 읽고, 원하면 행을 지워 사이트에서도 지울 수 있어요.

## 1. 시트 만들기
1. https://sheets.new 를 열어 새 시트를 만들고, 이름을 `결혼마을 편지함` 처럼 바꿔요.
2. 메뉴 **확장 프로그램 → Apps Script** 를 눌러요. 코드 편집 창이 새 탭으로 열려요.

## 2. 코드 붙여넣기
1. 편집 창에 있던 내용(`function myFunction() {…}`)을 모두 지워요.
2. 이 폴더의 **`tools/letters-sheet.gs`** 파일을 메모장으로 열어 내용 전체를 복사해 붙여 넣어요.
3. 💾 저장(Ctrl+S). 프로젝트 이름은 아무거나 괜찮아요.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**.
2. 왼쪽 위 톱니(유형 선택) → **웹 앱**.
3. 설명: 아무거나 · **다음 사용자 인증 정보로 실행: 나** · **액세스 권한이 있는 사용자: 모든 사용자**
   ← 이 두 가지가 중요해요. '모든 사용자'가 아니면 하객의 편지가 저장되지 않아요.
4. **배포** → **액세스 승인** → 내 구글 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면
   **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**.
   (방금 내가 만든 스크립트라서 구글이 확인되지 않은 앱이라고 경고할 뿐이에요)
5. 화면에 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사해요.

## 4. 사이트에 넣기
`config.js` (한 파일 버전은 `결혼마을.html` 안의 `window.WEDDING = {` 아래) 에서:

```js
lettersSheet: 'https://script.google.com/macros/s/…/exec',   // 3-5에서 복사한 주소
lettersSite: 'main',                                           // 시트 안의 탭 이름
```

- 실제 결혼식이면 예시 편지는 `letters: [],` 로 비워요.
- 저장한 뒤 사이트를 열고 편지를 한 통 보내 보세요. 시트에 `main` 탭이 생기고 한 줄이 들어오면 성공이에요.

## 알아두기
- 시트에서 행을 지우면 사이트에서도 사라져요. (부적절한 편지 정리)
- 시트 하나로 결혼식 여러 개를 쓸 땐 `lettersSite` 를 서로 다르게 적어요. 탭이 따로 생겨요.
- 코드를 고친 뒤엔 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영돼요. URL은 그대로예요.
- 시트 자체는 아무에게도 공유하지 않아도 돼요. 스크립트가 '나'로 실행되기 때문이에요.
- 연결이 안 되는 동안 쓴 편지는 하객 휴대폰에 보관됐다가, 다음에 사이트를 열 때 자동으로 보내져요.
- 무료 한도는 하루 수만 번 호출이라 결혼식 규모로는 넉넉해요.
