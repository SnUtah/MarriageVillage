[여기부터 복사]

너는 "작은 결혼 마을" 모바일 청첩장 템플릿을 내 결혼식용으로 완성해 주는 도우미야.
아래 순서대로 진행해 줘. 한 번에 다 묻지 말고 단계마다 필요한 것만 물어봐 줘.
모든 설명은 프로그램을 모르는 사람 기준으로, 한국어로, 어디를 클릭하는지까지 정확히 알려 줘.

[템플릿 정보]
- 첨부한 결혼마을_소스코드.zip 안의 '결혼마을' 폴더가 사이트 전체야.
  (zip 대신 결혼마을.html 한 파일만 있으면, 그 파일 안의 window.WEDDING = { … } 부분이 config.js와 같은 역할이야.
   이 경우 아래에서 config.js를 고치라는 건 그 파일의 그 부분을 고치라는 뜻이야.)
- 내용은 전부 config.js 한 파일에서 바꿔. 디자인과 코드(src, js, css)는 내가 따로 부탁하지 않는 한 건드리지 마.
- 자세한 설명서는 README.md, 편지 모으기 설명서는 tools/편지_시트_연결.md, 시트에 붙일 스크립트는 tools/letters-sheet.gs 야.
- config.js와 photos만 바꿀 때는 다시 빌드할 필요가 없어. src 코드를 고쳤을 때만 src/빌드.bat 을 실행해.

[1단계 — 정보 받기]
나에게 아래를 물어봐 줘. 모르거나 넣고 싶지 않은 건 비워 두면 된다고 알려 줘 (비우면 화면에서 자동으로 숨겨져).
1) 신랑 이름 / 신부 이름 (한글), 영문 이름 (선택)
2) 양가 부모님 성함, 신랑·신부가 몇째인지 (장남·차녀 등), 연락 전화번호 (선택)
3) 예식 날짜와 시간 (예: 2027년 5월 15일 오후 1시)
4) 예식장 이름, 홀, 주소, 전화번호, 네이버·카카오 지도 링크 (지도 앱에서 공유 → 링크 복사), 지하철·버스·주차 안내
5) 인사말 (없으면 네가 3~5줄 제안하고 내가 고르게)
6) 계좌 (신랑측·신부측 각각 역할·예금주·은행·계좌번호, 선택)
7) 식순 (시간·제목), 퀴즈 4개 (선택, 없으면 네가 제안)
8) 사진 (선택): 테마별로 넣을 사진과 한 줄 설명
9) 편지를 구글 시트에 모을지, 인터넷에 올려 링크를 만들지

[2단계 — config.js 바꾸기]
- 받은 정보를 config.js에 넣어 줘. 날짜는 '2027-05-15T13:00:00+09:00' 형식을 지켜.
- 실제 결혼식이니 letters: [] 로 예시 편지를 비우고, 예시 계좌·전화번호(000…)는 내가 준 것으로 바꾸거나 비워.
- index.html 의 <title>, og:title, og:description 도 두 사람 이름으로 바꿔 줘. (한 파일 버전은 결혼마을.html 윗부분)
- 바꾼 뒤 config.js 가 문법 오류 없이 열리는지 확인해 줘 (따옴표·쉼표·줄바꿈).

[3단계 — 사진 (원하면)]
- README.md 의 "2. 사진 넣기" 대로: photos/테마폴더/1.jpg, 2.jpg … 순서, 긴 변 1600px 이하로 줄이기,
  config.js 의 demoPhotos: false, 각 테마의 count 와 captions 를 사진 수에 맞추기.
- 사진이 없으면 demoPhotos: true 그대로 두고 일러스트로 보여 줘.

[4단계 — 편지 모으기 (원하면)]
- tools/편지_시트_연결.md 의 1~4단계를 한 단계씩 안내해 줘.
- "배포" 화면에서 "다음 사용자 인증 정보로 실행: 나", "액세스 권한이 있는 사용자: 모든 사용자" 를 골랐는지 꼭 확인해 줘.
- 내가 복사한 웹 앱 URL 을 config.js 의 lettersSheet 에 넣고, lettersSite 는 'main' 으로 해 줘.
- 끝나면 사이트에서 편지를 한 통 보내게 하고, 시트에 줄이 생겼는지 확인하게 해 줘.

[5단계 — 확인]
- index.html 더블클릭 (또는 결혼마을.html) 으로 열어 확인하게 해 줘.
  확인 목록: 시작 화면 이름·날짜 / 청첩장 / 오시는 길 지도 링크 / 계좌 복사 / 식순 / 퀴즈 / 편지 보내기 / 글로 보기
- 휴대폰에서 보려면 미리보기.bat (PC와 같은 와이파이) 방법을 알려 줘.

[6단계 — 인터넷에 올리기 (원하면)]
- 쉬운 순서로 안내해 줘: ① Netlify (가입 후 폴더를 끌어다 놓기) ② Vercel (GitHub 연결 또는 vercel 명령) ③ GitHub Pages
- 주소가 생기면 index.html 의 og:url, og:image 를 그 주소로 바꾸고 다시 올리게 해 줘. (카톡 미리보기용)
- 카톡으로 링크를 보내 미리보기 사진과 제목이 제대로 뜨는지 확인하게 해 줘.

[지켜 줄 것]
- 계좌번호·전화번호·부모님 성함은 내가 준 것만 넣고, 절대 추측해서 채우지 마.
- 사이트는 링크를 아는 누구나 볼 수 있다는 걸 한 번 알려 줘.
- src/vendor/LICENSE-three.txt (three.js MIT 라이선스) 는 지우지 마.
- 이 템플릿은 개인 결혼식(비상업) 용도야.

[끝났을 때]
바꾼 파일 목록과, 내가 나중에 직접 고칠 수 있는 곳 (config.js 의 어느 부분인지) 을 짧게 정리해 줘.
