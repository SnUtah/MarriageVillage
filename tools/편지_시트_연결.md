# 💌 Collect letters in a Google Sheet (10 minutes, free)

The site has no server. Left as it is, a guest's letter stays **only on that guest's phone**.
If you use one Google Sheet as the "mailbox server", letters gather in the sheet and every guest can read them in the mailbox.
The couple opens the sheet to read the letters, and can delete a row to remove a letter from the site too.

Menu names below are from Google's English interface. If your Google account shows Korean menus, see [Korean menu names](#korean-menu-names) at the end.

## 1. Make the sheet
1. Open https://sheets.new to make a new sheet, and rename it to something like `Wedding village mailbox`.
2. Click the menu **Extensions → Apps Script**. A code editor opens in a new tab.

## 2. Paste the code
1. Delete everything that's already in the editor (`function myFunction() {…}`).
2. Open **`tools/letters-sheet.gs`** from this folder in Notepad, copy all of it and paste it in.
3. 💾 Save (Ctrl+S). Any project name is fine.

## 3. Deploy it as a web app
1. Top right: **Deploy → New deployment**.
2. Top left: the gear (Select type) → **Web app**.
3. Description: anything · **Execute as: Me** · **Who has access: Anyone**
   ← These two matter. If it isn't "Anyone", guests' letters won't be saved.
4. **Deploy** → **Authorize access** → pick your Google account → if a "Google hasn't verified this app" screen appears:
   **Advanced → Go to (project name) (unsafe)** → **Allow**.
   (Google warns only because it's a script you just made yourself.)
5. Copy the **Web app URL** shown on the screen (`https://script.google.com/macros/s/…/exec`).

## 4. Add it to the site
In `config.js` (for the single-file version, below `window.WEDDING = {` inside `결혼마을.html`):

```js
lettersSheet: 'https://script.google.com/macros/s/…/exec',   // the URL you copied in 3-5
lettersSite: 'main',                                           // the tab name inside the sheet
```

- For a real wedding, empty the sample letters with `letters: [],` (in `window.WEDDING_EN` too, if you kept it).
- Save, open the site and send one letter. If a `main` tab appears in the sheet with one row in it, it worked.

## Good to know
- The script makes the tab and its header row by itself. The header row is in Korean: `시간` (time), `이름` (name), `측` (side), `메시지` (message), `id`. Leave the header row and the column order as they are; the script reads the columns by position.
- The side column holds `신랑측` (groom's side) or `신부측` (bride's side). Keep these Korean values; the site shows them in English for English visitors.
- Deleting a row in the sheet removes the letter from the site too. (Useful for clearing out inappropriate letters.)
- To use one sheet for several weddings, give each one a different `lettersSite`. Each gets its own tab.
- After changing the code, do **Deploy → Manage deployments → ✏️ (Edit) → Version: New version → Deploy**, or the change won't take effect. The URL stays the same.
- You don't need to share the sheet with anyone, because the script runs as "Me".
- Letters written while the connection is down are kept on the guest's phone and sent automatically the next time the site opens.
- The free limit is tens of thousands of calls a day, which is plenty for a wedding.
